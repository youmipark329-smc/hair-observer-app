세션 종료 요약

자동 집계

설정

비우면 기기 시계(안드로이드 자동 날짜·시각 = 외부망 NTP) 를 사용합니다. 이때 오프셋은 측정하지 않으므로 CSV 에 빈 값으로 남습니다(0 이 아닙니다 — 0 은 '측정했더니 0 ms' 라는 뜻이 되어 동기 게이트를 거짓 통과시킵니다). 입력 시 앱이 60초마다 이 주소로 서버시각을 받아 오프셋+왕복지연 을 계산합니다(JSON {now:epoch_ms} 또는 HTTP Date 헤더 지원 · CORS 허용 필요).

실명·이니셜은 넣지 않습니다. OBS-NN ↔ 실명 대응은 위임 로그(delegation log)에 두고, 연결로그와 같은 등급으로 보관합니다.

여기서 고른 병동이 새 세션의 기본값이 됩니다. 세션마다 시작화면에서 바꿀 수 있습니다.

연결로그에 배정된 익명ID만 넣습니다. 형식(P-16E-001)에 맞지 않는 줄은 저장 시 버려집니다. 실명·등록번호·생년월일은 절대 넣지 마세요 — 이 목록은 폰에 저장됩니다.
